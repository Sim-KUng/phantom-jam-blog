# 2차선 시공간 다이어그램 생성 및 분석

지금까지의 실험은 평균 속도, throughput, 차선 변경 횟수, 급감속 횟수처럼 숫자로 집계된 지표를 중심으로 진행했다. 이런 숫자 지표는 전체적인 경향을 요약해 주지만, 정체 파동이 언제 어디서 발생했는지, 그리고 그 파동이 에이전트 투입 전후로 어떻게 달라졌는지를 한눈에 보여주지는 못한다.

Week 13에서는 시공간 다이어그램(Space-Time Diagram)을 사용해 이 질문에 시각적으로 답한다. 차량이 어느 시각에 도로의 어느 위치를 지나갔는지를 2차원 평면에 표현하고, 색상으로 속도를 나타낸다. 이 시각화를 통해 정체 파동이 도로를 따라 어떻게 역방향으로 전파되는지, 그리고 PPO 에이전트가 그 파동에 어떤 영향을 미치는지를 직접 확인할 수 있다.

---

## 1. 시공간 다이어그램이란

시공간 다이어그램은 교통공학에서 오랫동안 사용되어 온 시각화 방식이다.

```text
X축: 도로 위치 (m)
Y축: 시간 (s)
색상: 해당 위치·시각의 차량 평균 속도 (m/s)
```

이 다이어그램에서 정체가 발생하면 빨간색(저속) 영역이 나타난다. phantom jam의 특징은 이 빨간 영역이 시간이 지남에 따라 도로의 역방향(오른쪽에서 왼쪽)으로 이동한다는 점이다. 즉, 다이어그램에서 빨간 줄기가 오른쪽 아래에서 왼쪽 위 방향으로 기울어진 대각선 형태로 나타나면 phantom jam 파동이 역전파되고 있다는 의미다.

```text
Phantom Jam 특징 (시공간 다이어그램에서):
┌───────────────────────────────────────┐
│ t=40s ●← 느린 파동이 왼쪽으로 이동   │
│ t=30s   ●←                           │
│ t=20s     ●←                         │
│ t=10s       ●←                       │
│       x=100  x=300  x=500  x=700     │
└───────────────────────────────────────┘
빨간(저속) 영역이 오른쪽 아래 → 왼쪽 위 방향으로 기울어짐
```

PPO 에이전트가 이 파동을 억제하면 빨간 영역이 줄거나, 대각선이 수직에 가까운 형태로 바뀐다.

## 2. 실험 설계

### 2-1. 비교 조건

이번 시각화에서는 두 가지 조건을 비교했다.

```text
조건 1 — Baseline (0% PPO):
  PPO 에이전트 없음. controlled_vehicle 1대가 IDLE(현재 속도 유지) action을 사용하고,
  나머지 차량은 모두 IDM(Intelligent Driver Model)으로 주행한다.

조건 2 — RL Agent (5% PPO):
  전체 60대 중 3대(5%)를 ppo_2lane_week12_stable_final 모델로 제어한다.
  나머지 57대는 IDM.
```

### 2-2. 시뮬레이션 파라미터

```python
VEHICLES_COUNT       = 60
LANES_COUNT          = 2
DURATION             = 200   # steps (기존 50 → 200, 파동 가시화를 위해 연장)
SIMULATION_FREQUENCY = 15    # Hz
POLICY_FREQUENCY     = 5     # Hz → step 당 0.2초
# 총 시뮬레이션 시간 = 200 / 5 = 40초
```

기존 Week 10~12 실험은 모두 `duration=50` steps(10초)로 진행했다. 하지만 10초짜리 시뮬레이션에서는 phantom jam 파동이 충분히 전파되기 전에 에피소드가 끝나버린다. Week 13에서는 `duration=200`으로 늘려 40초 시뮬레이션을 수행했다.

### 2-3. 수집 데이터

매 step마다 모든 차량에 대해 다음 정보를 기록했다.

```text
step         : policy step 번호 (0~199)
time_sec     : 경과 시간 (s) = step / 5
vehicle_id   : 차량 식별자
x_position   : 도로 위 종방향 위치 (m)
speed        : 현재 속도 (m/s)
lane_index   : 차선 (0=1차선, 1=2차선)
is_controlled: PPO 제어 차량 여부
```

## 3. 시각화 방법

### 3-1. 히트맵 격자 방식

시공간 다이어그램은 산점도 대신 **2차원 격자 집계(bin aggregation)** 방식으로 생성했다.

```text
1. 위치 축을 X_BINS=200개 구간으로 분할
2. 시간 축을 T_BINS=200개 구간으로 분할
3. 각 격자 셀 (위치 구간 × 시간 구간)에 속하는 차량들의 평균 속도를 계산
4. 평균 속도를 RdYlGn 컬러맵으로 표현
   (빨강 → 노랑 → 초록 = 저속 → 중속 → 고속)
```

이 방식은 개별 차량 궤적 선을 그리는 것보다 전체 교통 상태 필드를 자연스럽게 표현한다. 차량이 밀집되어 느리게 이동하는 구간은 진한 빨간색, 차량이 빠르게 통과하는 구간은 초록색으로 나타난다.

### 3-2. 차선 분리

2차선 도로이므로 차선별로 별도의 시공간 다이어그램을 생성했다.

```text
1차선 (lane_index=0): 오른쪽 차선 (y ≈ 0m)
2차선 (lane_index=1): 왼쪽 차선  (y ≈ 4m)
```

각 차선의 다이어그램을 Baseline과 RL Agent 조건으로 나란히 비교하여 차선별 정체 패턴 차이를 확인했다.

## 5. Baseline 시공간 다이어그램

<div align="center">

![Baseline 2-Lane Spacetime](/img/week13_spacetime_baseline_only.png)

<p><em>Baseline (0% PPO) — 1차선(좌)·2차선(우) 시공간 다이어그램</em></p>

</div>

Baseline 조건에서는 PPO 에이전트 없이 60대의 IDM 차량이 2차선 도로를 주행한다.

시공간 다이어그램에서 주목할 점은 다음과 같다.

```text
관찰 포인트:
1. 빨간 영역의 분포
   - 빨간(저속) 구간이 어느 위치·시각에 나타나는가
   - 빨간 영역이 시간이 지남에 따라 왼쪽(역방향)으로 이동하는가

2. 정체 파동의 형태
   - 빨간 영역이 대각선 형태(/ 또는 \)로 기울어져 있으면
     파동이 역전파되는 phantom jam 특성을 보이는 것이다

3. 차선 간 차이
   - 1차선과 2차선에서 정체 패턴이 다른가
   - 어느 차선에서 먼저 정체가 시작되는가
```

IDM 차량은 앞 차와의 안전 거리를 유지하려는 반응 지연으로 인해 정체 파동을 생성한다. 차량 밀도가 높은 구간(vehicles_density=2.0, 60대)에서 이 파동이 뚜렷하게 나타난다.

![RL Agent 2-Lane Spacetime](/img/week13_spacetime_rl_only.png)

<p><em>RL Agent (5% PPO) — 1차선(좌)·2차선(우) 시공간 다이어그램</em></p>

</div>

5% 침투율 조건에서는 60대 중 3대가 PPO 정책으로 제어된다.

RL 조건의 시공간 다이어그램에서 주목할 점은 다음과 같다.

```text
관찰 포인트:
1. 빨간 영역의 변화
   - Baseline 대비 빨간 구간이 줄었는가, 늘었는가
   - 빨간 영역의 역전파 기울기가 완화되었는가

2. 속도 분포의 균일성
   - 전체적으로 색상이 더 균일(초록 위주)해졌는가
   - 아니면 빨간·초록이 더 극단적으로 나뉘어 있는가

3. Throughput 시각적 확인
   - Week 12에서 throughput이 증가(약 6.3배)했다면,
     시공간 다이어그램에서 초록 영역이 도로 후반부(x > 400m)까지
     더 넓게 분포하는지 확인 가능
```

Week 12 행동 지표 평가에서 5% PPO 조건은 throughput을 2.80에서 6.30으로 증가시켰다. 그러나 동시에 차선 변경(4배 증가)과 급감속(16% 증가)도 늘었다. 이 복합적인 결과가 시공간 다이어그램에서 어떻게 나타나는지가 이번 시각화의 핵심이다.

## 8. 전체 2차선 개요

<div align="center">

![2-Lane Overview](/img/week13_spacetime_2lane_overview.png)

<p><em>2×2 전체 개요 — Baseline(상단) vs RL Agent(하단), 1차선(좌) vs 2차선(우)</em></p>

</div>

2×2 개요 그림은 네 가지 조건을 동일한 색상 스케일로 한 화면에서 비교할 수 있게 해준다.

```text
행 1 (상단): Baseline 조건
  좌: 1차선 | 우: 2차선

행 2 (하단): RL Agent 5% 조건
  좌: 1차선 | 우: 2차선
```

이 그림에서 다음 질문에 답할 수 있다.

```text
1. 차선 간 비대칭성
   - 두 차선 중 한 차선에서만 정체가 집중되는가
   - RL 에이전트가 특정 차선에 편향된 행동을 보이는가

2. 조건 간 일관성
   - Baseline에서 두 차선 모두 phantom jam이 나타나는가
   - RL 조건에서 두 차선 모두 일관된 방향으로 변화했는가

3. 전체 도로 흐름
   - 두 차선 전체에서 평균적인 속도 색상이 어떻게 달라졌는가
```

## 9. 시공간 다이어그램으로 본 Week 12 결과 재해석

Week 12에서 확인한 수치 결과를 시공간 다이어그램 관점에서 다시 해석하면 다음과 같다.

### 9-1. Throughput 증가 (2.80 → 6.30)

```text
수치 해석: 기준 지점(x=500m)을 통과한 차량 수가 약 2.25배 증가.

시공간 다이어그램에서 예상되는 모습:
- RL 조건에서 도로 중후반부(x=400~600m)에 초록 영역이 더 넓게 분포
- 차량이 x=500m를 더 빠르게 통과하므로, 해당 구간의 궤적 밀도가 높아짐
```

### 9-2. 평균 속도 감소 (17.34 → 14.95 m/s)

```text
수치 해석: 전체 평균 속도가 약 14% 낮아졌다.

시공간 다이어그램에서 예상되는 모습:
- RL 조건에서 전반적으로 색상이 초록 대신 노란색 위주로 나타날 수 있음
- 특히 RL 에이전트 주변 구간에서 노란(중속) 영역이 형성될 가능성
```

### 9-3. 차선 변경 증가 (1.00 → 4.00회)

```text
수치 해석: 차선 변경이 4배 증가.

시공간 다이어그램에서 예상되는 모습:
- 차선 변경 순간 주변 차량이 감속하면서 국소적 빨간 반점이 생성될 수 있음
- 1차선↔2차선 경계에서 교란 패턴이 증가할 수 있음
```

### 9-4. Crash 증가 (2.00 → 3.40회)

```text
수치 해석: 충돌 차량 수가 약 1.7배 증가.

시공간 다이어그램에서 예상되는 모습:
- 충돌 차량은 속도가 0이 되므로 특정 위치·시각에 진한 빨간 점으로 나타남
- 충돌 직전 구간에서 급격한 색상 변화(초록 → 빨강)를 관찰할 수 있음
```

Week 13에서는 시공간 다이어그램을 통해 Week 12까지의 수치 기반 평가를 시각적 관점에서 보완했다.

시공간 다이어그램의 핵심 기여는 다음과 같다.

```text
1. 정체 파동의 시각적 확인
   - phantom jam의 역전파 파동을 직접 눈으로 볼 수 있다
   - 에이전트 투입 전후로 파동 형태가 어떻게 달라졌는지 비교 가능

2. 차선별 영향 분리
   - 1차선과 2차선에서 정체 패턴이 다를 수 있음을 차선별 다이어그램으로 확인
   - PPO 에이전트의 행동이 어느 차선에서 더 큰 영향을 미쳤는지 파악

3. 수치 결과와 시각 결과의 통합 해석
   - throughput 증가, 평균 속도 감소, 차선 변경 증가, crash 증가라는
     서로 다른 방향의 수치 변화가 시각적으로 어떻게 나타나는지 확인
```

시공간 다이어그램은 단순히 예쁜 그림이 아니라, 교통 흐름의 동역학을 공간과 시간 축에서 동시에 보여주는 도구다. 이번 시각화를 통해 PPO 에이전트가 phantom jam 파동을 "얼마나" 억제했는지를 숫자를 넘어서 직관적으로 이해할 수 있다.

### 12-2. 핵심 수치 결과 정리

아래 표는 `ppo_2lane_week12_stable_final` 모델 기준 최종 평가 결과다(Week 12 행동 지표 평가).

| 지표 | Baseline (0%) | PPO 5% | PPO 10% |
|------|:---:|:---:|:---:|
| 평균 속도 (m/s) | 17.34 | 14.95 | 15.87 |
| Throughput (대) | 2.80 | **6.30** | **6.70** |
| 차선 변경 (회) | 1.00 | 4.00 | 6.90 |
| 급감속 (회) | 395.80 | 458.30 | 466.80 |
| 충돌 차량 (대) | 2.00 | 3.40 | 7.20 |

**가설 검증 요약:**

```text
✅ 가설 지지 (Throughput)
   Baseline 2.80 → 5% 6.30 → 10% 6.70
   단 5%의 에이전트 투입만으로 throughput이 약 2.25배 증가했다.
   이는 소수의 자율주행 차량이 전체 교통 흐름에 유의미한 양의 영향을 줄 수 있음을 보여준다.

⚠️  부분 지지 (속도 균일화)
   평균 속도는 오히려 소폭 감소(17.34 → 14.95 m/s)했지만,
   더 많은 차량이 중간 속도로 안정적으로 흐른 것으로 해석된다.
   시공간 다이어그램에서 노란(중속) 궤적의 증가로 확인된다.

❌ 가설 미지지 (안정성)
   차선 변경 4배, 급감속 16% 증가, crash 70% 증가.
   단일 에이전트 학습 정책을 다중 차량에 그대로 투입하면
   개별 에이전트의 공격적 행동이 주변 차량의 불안정성을 키운다.
```

### 12-3. 시공간 다이어그램이 말해주는 것

```text
Baseline (0% PPO):
  빨간(저속) 대각선 밴드가 도로 역방향(오른쪽 → 왼쪽)으로 전파됨.
  이것이 phantom jam의 특징적인 시각 패턴이다.
  차량들은 앞 차와의 안전 거리 유지를 위한 반응 지연으로 정체 파동을 만든다.

RL Agent (5% PPO):
  빨간 구간의 분포가 달라진다. 에이전트가 속도를 조절하며 흐름을 만들어내는 구간에서
  궤적이 더 균일한 노란·초록색으로 나타난다.
  다만 에이전트가 차선 변경을 시도하는 순간 주변에 국소적 빨간 반점이 생기기도 한다.

핵심 인사이트:
  throughput 증가 = 더 많은 차량이 빠르게 지점을 통과
  ↔ 그 과정에서 주변 차량을 더 자주 교란
  이 두 효과가 동시에 나타나는 것이 현재 5% 단일 PPO 정책의 특성이다.
```

### 12-4. 이번 실험에서 막혔던 부분들

환경 쪽에서 헷갈렸던 것들:

- `duration`이 steps 단위인 줄 알고 `duration=200`으로 설정했는데, 실제로는 초(s) 단위였다. 그래서 200초짜리 에피소드가 되어버렸고, 나중에 `duration=40`으로 수정해서 40초 = 200 policy steps 기준으로 맞췄다.
- `_is_terminated()`가 controlled vehicle 충돌 시 즉시 `True`를 반환하는데, 이걸 모르고 실행했더니 에피소드가 4초 만에 끝나버렸다. `NoCrashTerminationWrapper`로 감싸서 해결했다.
- 침투율 5%, 10% 조건에서는 `MultiAgentObservation` / `MultiAgentAction`으로 설정해야 한다. 단일 에이전트 설정 그대로 쓰면 observation shape 오류가 난다.

시각화 쪽에서 막혔던 부분:

- 처음에 2D 히스토그램(heatmap) 방식으로 만들었는데 이미지가 전부 하얗게 나왔다. 원인은 데이터가 희소해서 bin 대부분이 NaN이 된 것이었다. scatter plot으로 바꾸니까 바로 해결됐다.

강화학습 쪽:

- 단일 에이전트로 학습한 정책을 여러 대에 그대로 올리면 각 에이전트가 서로의 행동을 전혀 모르기 때문에 충돌이 늘어난다. throughput이 올라가는 동시에 crash도 같이 늘어난 이유가 여기 있었다.
- 보상 함수에서 `w_hard_brake`를 높이면 급감속은 줄지만 throughput 개선폭도 줄어든다. 두 지표를 동시에 잡기가 생각보다 어려웠다.
